2. Project Setup

This chapter creates a frontend project, installs CallioText with all of its dependencies, and lays out a split-screen page frame that serves as the canvas for the whole tutorial: the editor will live in the left half, the printer in the right. It is all routine work; if you are used to setting up React projects, skim through it.

Create the project

Create a React + TypeScript project with Vite:

npm create vite@latest my-calliotext-app -- --template react-ts
cd my-calliotext-app
npm install

Install CallioText

npm install @project-callio/calliotext

npm installs its peer dependencies alongside (if your package manager does not auto-install peer dependencies, install the packages in the table below by hand). Your code will use these libraries directly later on, so here is what each one is:

DependencyRole
slate / slate-history / slate-reactSlate is a library for building editors; it handles cursors, selection, input, and undo/redo. CallioText's concept system is built on top of it.
@mui/material and the two emotion packagesMUI is the React component library the default interface is built with; emotion is the styling engine MUI depends on.
@ftyyy/mouselessProvides keyboard-only navigation support.

Import the stylesheet

CallioText ships one stylesheet, imported once at the project entry. In src/main.tsx, add:

import "@project-callio/calliotext/calliotext.css"

Lay out the page frame

The whole tutorial works on one canvas: editor on the left half of the screen, printer on the right, so every change can be checked against both the editing view and the output view. Replace the content of src/App.tsx with the following. Both halves are placeholders for now: 

import React from "react"

// Each half takes one side of the screen.
const half: React.CSSProperties = {
    position: "absolute", top: 0, height: "100%", width: "49%",
}

export default function App(){
    return <div style={{position: "absolute", inset: 0}}>
        <div style={{...half, left: 0}}>
            {/* chapter 3: the editor goes here */}
        </div>
        <div style={{...half, left: "51%"}}>
            {/* chapter 4: the printer goes here */}
        </div>
    </div>
}

One thing to watch: CallioText's default components fill their parent container using absolute positioning, so the parent must have a definite size or the component will have no visible height. The code above pins the outermost container to the viewport with position: absolute; inset: 0, and the two halves position themselves inside it.

Check that everything is ready

npm run dev

Open the address it prints (usually http://localhost:5173). If the page is blank with no errors in the terminal or the browser console, the project is ready. In the next chapter the left half gets a working editor.
