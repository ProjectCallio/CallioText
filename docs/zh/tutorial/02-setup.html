2. 准备工程

这一章我们创建一个前端工程，装好 CallioText 和它的全部依赖， 再搭一个左右分栏的空白页面框架，作为整个教程共用的画布：左半边以后放编辑器，右半边放印刷器。 内容都是常规操作，如果你熟悉 React 工程的搭建，可以快速扫过。

创建工程

用 Vite 创建一个 React + TypeScript 工程：

npm create vite@latest my-calliotext-app -- --template react-ts
cd my-calliotext-app
npm install

安装 CallioText

npm install @project-callio/calliotext

npm 会连同它的 peer 依赖一起装上（如果你的包管理器不自动安装 peer 依赖， 把下表里的包手动装一遍即可）。这些库你的代码之后会直接用到，认识一下：

依赖它是做什么的
slate / slate-history / slate-reactSlate 是一个专门用来构建编辑器的底层库，负责光标、选区、输入、撤销重做这些最基础的编辑功能。CallioText 的概念系统就建立在它上面。
@mui/material 和两个 emotion 包MUI 是一套 React 组件库（按钮、抽屉、提示框等），CallioText 的默认界面用它搭建。emotion 是 MUI 依赖的样式引擎。
@ftyyy/mouseless提供全键盘操作（不用鼠标）的支持。

引入样式表

CallioText 自带一份样式文件，需要在工程入口引入一次。打开 src/main.tsx，在最上面加一行： 

import "@project-callio/calliotext/calliotext.css"

搭一个页面框架

整个教程我们都会在同一个画布上工作：屏幕左半边放编辑器，右半边放印刷器， 这样每次修改都能立刻对照「编辑的样子」和「输出的样子」。 把 src/App.tsx 的内容整个换成下面这样。现在两边都还是空的，只是把位置占好： 

import React from "react"

// 左右各占一半的样式。
const half: React.CSSProperties = {
    position: "absolute", top: 0, height: "100%", width: "49%",
}

export default function App(){
    return <div style={{position: "absolute", inset: 0}}>
        <div style={{...half, left: 0}}>
            {/* 第 3 章：这里放编辑器 */}
        </div>
        <div style={{...half, left: "51%"}}>
            {/* 第 4 章：这里放印刷器 */}
        </div>
    </div>
}

一个注意点：CallioText 的默认组件用绝对定位铺满父容器，所以父容器必须有确定的尺寸， 否则组件没有可见的高度。上面的代码用 position: absolute; inset: 0 让最外层容器铺满视口，两个半边再各自定位。

确认一切就绪

运行开发服务器：

npm run dev

在浏览器打开它给出的地址（通常是 http://localhost:5173）。 如果页面是一片空白、终端和浏览器控制台都没有报错，工程就准备好了。 下一章，我们让左半边出现一个真正能打字的编辑器。
