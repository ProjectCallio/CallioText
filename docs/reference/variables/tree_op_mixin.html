            editor: EditorComponent,
            paths: number[][],

        这个函数按路径批量删除节点。 按显式路径删除，不依赖当前选区，因此在编辑器没有焦点时（比如在effect里）也能正常工作。 无效或已失效的路径会被静默忽略。
