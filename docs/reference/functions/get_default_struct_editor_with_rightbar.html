      这个函数返回一个默认的结构节点组件。这个节点需要用户确定其子节点数量以及每个子节点的宽度，并自动创建和删除子节点，使得子节点的 数量和给定的一致，并且自动调整子节点的宽度。 用户给出的宽度会被理解为比例，如果用户给出的宽度不足，则自动用1填充。
